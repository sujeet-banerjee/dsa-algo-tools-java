Install and Compile
--------------------
Install Open-JDK version 21
Save the Test.java.txt file, and Rename the file Test.java.txt to Test.java
Compile the java file:   <path_to_java>/bin/javac  Test.java
Ensure a file name Test.class gets created. You may need to fix issues / bugs in order to make it compliable.
Run the generated bytecode (Test class): <path_to_java>/bin/java  Test
